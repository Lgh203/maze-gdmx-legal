《迷宫闯关大冒险》隐私政策

更新及生效日期：2026年10月11日　政策版本：1.0

兰溪市叙禾网络科技有限公司（以下简称“我们”）重视您的个人信息与隐私安全。本政策说明您使用《迷宫闯关大冒险》（以下简称“本游戏”）时，相关信息的处理方式。请您在首次使用前认真阅读；您可在启动页及游戏内随时查看本政策和用户协议。

本版本的重要说明：本游戏提供本地单机玩法，无需注册或输入姓名、身份证号、手机号、密码等信息。游客入口只用于开始本地游戏，不创建网络账号，也不进行身份验证。当前版本不接入荣耀账号、广告、支付、行为统计或云存档服务。首次启动的隐私选择不会预先勾选；拒绝时不启动游戏，您仍可阅读法律文档或退出。

屏幕尺寸、系统版本及设备兼容信息游戏运行时在设备本地使用必要的屏幕与系统环境信息，用于图形显示、声音播放和兼容性适配；不建立设备画像，不上传给我们。

您主动联系时提供的邮箱、问题描述及附件仅在您主动联系时处理，用于答复咨询、处理隐私请求与定位您描述的问题。请勿发送身份证照片、密码等与咨询无关的敏感信息。处理完毕后仅在解决问题与满足依法保存义务所必需的期限内留存。

本版本不收集通讯录、短信、通话记录、精确位置信息、照片、摄像头或麦克风内容；不读取应用安装列表，不为广告或分析获取设备标识。游戏操作及关卡数据在本机处理。

三、设备权限与网络访问

本版本安装包不声明互联网访问权限，游戏及内置法律文档无需联网。游戏不需要相机、麦克风、定位、通讯录、电话或外部存储等敏感权限。法律文档使用禁用 JavaScript 及网络访问的本地 WebView 阅读，仅加载安装包内的文档资源，不读取您的其他文件；我们不通过文档设置营销 Cookie 或追踪标识。只有您主动点击在线版本按钮时，应用才交由系统浏览器打开网页；浏览器的网络与数据处理适用浏览器服务及 GitHub 网站的规则。

四、存储期限与安全

游戏存档、设置和隐私选择保存在您的设备应用私有空间，我们不提供服务器副本或云同步。本游戏不主动进行联网备份。您可在游戏内选择清除本机游戏数据，或通过 Android 的应用存储设置清除全部本地数据，也可卸载游戏。清除后进度无法通过我们的服务器恢复。设备迁移、系统功能及第三方备份工具的行为由您所用系统或服务的规则决定。

我们对需要处理的客服及隐私请求信息限制访问范围，仅保存完成处理与履行法定义务所必需的信息。在线文档使用 HTTPS；法律文档托管于 GitHub Pages，托管方的存储、安全及访问日志处理适用其公开的隐私声明。请妥善保管您的设备，避免将本地存档交给不可信软件。

五、您的选择和权利

  • 查看政策：启动页和游戏内提供显著入口，可查看完整的隐私政策及用户协议。
  • 拒绝或撤回同意：首次启动可拒绝并退出；游戏内可撤回同意并返回启动页。撤回后，游戏停止继续启动；需要再次同意才能继续。撤回不会自动删除已有存档，您可另行清除应用数据。
  • 访问或删除本地数据：游戏界面展示您的关卡状态；您可在游戏内选择清除本机游戏数据，或在系统应用设置中清除全部应用数据。删除会重置相应存档，请在确认前注意提示。由于我们没有您的游戏存档服务器副本，无法代为恢复或远程删除您设备中的存档。
  • 咨询或行使个人信息权利：如需查阅、复制、更正、补充或删除您通过客服提供的信息，或提出与个人信息处理相关的意见，请通过下方邮箱联系。我们会在核实必要身份后及时处理，不索取与处理请求无关的信息。

本版本不创建网络账号，因此不存在本游戏网络账号的注销流程；清除本地数据即可删除本机保存的游戏及隐私选择记录。

适龄提示：开发者建议 8 周岁及以上，不等同于主管部门的年龄分级。未成年人应在监护人指导下阅读本政策、用户协议并合理安排游戏时间。建议每次游戏适时休息，避免沉迷。我们不会要求未成年人提交实名或联系方式用于本地游客入口；如您认为我们通过客服误收集了未成年人的相关信息，请联系下方邮箱，我们会核实并依法处理。

本版本的游客入口不等同于实名验证或防沉迷服务。未来若接入依法或发行平台要求的身份认证与未成年人保护功能，将先明确告知实际处理主体、必要信息及规则，并更新本政策。
