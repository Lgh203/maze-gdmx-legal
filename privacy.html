荣耀服务的个人信息说明：本游戏已接入必要的荣耀联运服务及其官方依赖。请一并阅读荣耀游戏联运 SDK 隐私声明和荣耀分析 SDK 隐私声明。应用内文档可离线阅读；点击第三方在线规则会由系统浏览器打开相应官方网页。

一、信息处理清单与用途

信息类别处理目的、方式与存储位置
荣耀登录标识与登录会话在您主动点击荣耀登录并完成 SDK 流程后，SDK 向荣耀服务发送必要请求并返回登录结果。本游戏在内存中使用 Open ID 确认登录及生成必要角色标识；不向您索取密码，不保存或展示原始登录 token，不请求头像或昵称。本游戏不建立独立用户账号服务器。荣耀账号和 SDK 自身的相关信息由荣耀按其规则处理。
实名校验与未成年人保护所需信息如荣耀平台要求实名或未成年人校验，相应官方流程可能直接处理您提交的姓名、身份证号及必要认证状态，用于身份校验与游戏时间管控。信息由荣耀流程及其服务处理，本游戏运营方不收取证件照片、姓名、身份证号或验证码，也不以本地按钮代替实名校验。
完整关卡存档、道具、游戏数值、音量及设置用于保存关卡与玩法，在本机应用私有存储中保存，不提供云存档。完整存档不上传给我们或荣耀；但下述必要角色与关卡摘要会由 SDK 上报，不能将此理解为所有游戏信息均不联网。
必要游戏角色、模式与关卡摘要成功登录进入游戏后及相关状态变化时，游戏向荣耀联运服务上报由 Open ID 衍生的角色标识、固定本地闯关区服标识、实际玩法模式名称及本机关卡进度数值，用于联运服务必需的游戏角色及进度记录。仅传输这些必要摘要，不上传完整游戏存档、其他文件或聊天内容。
SDK 设备、应用、网络及服务信息用于登录连接、服务兼容、安全保护、平台更新和必要服务分析；可能包含设备及系统/ROM/语言、SIM 国家码、运营商、包名版本、网络类型、IP 地址、OAID、UDID、AndroidID、应用随机标识符及 SDK 服务使用信息。由荣耀 SDK 在必要场景处理，详细范围见第二节及官方声明。游戏自身还在本地使用屏幕尺寸和系统信息进行画面、声音及输入适配。
隐私同意状态及已确认的政策版本在应用私有存储中本地保存，用于记录您的选择及重要政策更新后重新提示，不主动上传。游戏内可撤回同意并退出。
法律页面访问相关网络信息应用内为安装包中的本地全文，不产生页面网络请求。您主动选择“浏览器查看在线版本”或点击第三方在线规则时，系统浏览器打开相应网站；浏览器与托管方可能处理 IP 地址、请求信息与访问时间，用于交付页面和服务安全。本游戏不读取浏览器访问日志。我们的在线法律页面不嵌入广告、统计、追踪脚本或第三方字体。
您主动联系时提供的邮箱、问题描述及附件用于答复咨询、处理隐私请求与定位您描述的问题。请勿发送密码、验证码或与问题无关的证件资料；处理完毕后只在解决问题及依法保存所需期限内保留。

本游戏不申请通讯录、短信、电话、相机、麦克风、定位或外部存储等敏感权限，不读取这些内容。荣耀 SDK 会针对必要关联服务检查特定荣耀应用的可用性，见第三节。我们不出售您的个人信息，不利用个人信息开展本游戏广告营销。

四、存储期限、安全及信息提供

完整游戏存档、设置与隐私选择保存在本机应用私有空间，无游戏云存档副本，不主动进行完整存档联网备份。清除应用数据、卸载或设备损坏可能导致进度丢失，我们没有完整存档服务器副本可恢复。必要角色与关卡摘要由荣耀联运服务接收，不构成跨设备存档同步。

荣耀 SDK 登录、认证、设备、网络及必要游戏信息会按其服务规则传输并保存至中国大陆境内服务器。官方联运声明列明：相应登录账号信息在注销荣耀账号时删除；实名信息按其规则保留一年；网络安全、服务优化及风险控制相关信息按其规则保留三年。荣耀分析声明将相关上报信息保留一年，并将网络类型、传感器列表等指定信息仅在端侧处理。具体范围、期限与您的权利以本政策所链接的对应官方声明为准。

我们不持久保存原始登录 token、实名证件或头像昵称，不向第三方销售个人信息。必要信息提供给荣耀用于本政策说明的服务，荣耀与相关合作方的信息处理依据其官方声明；GitHub 法律页面访问另依托管声明处理。我们对客服与隐私请求信息限制访问，只保存完成处理与履行法定义务所需的信息。SDK 安全工具包及 HTTPS 用于通信保护。请妥善保管设备，避免向不可信软件提供存档、账号或验证码。

五、您的选择和权利

  • 查看或拒绝：启动页和游戏内随时提供完整政策与协议。首次拒绝时不启动荣耀服务和游戏，仍可阅读文档或退出；同意之后还需主动选择荣耀登录。
  • 撤回同意：在游戏设置中选择撤回并退出，游戏会停止运行，下一次打开重新提示阅读和选择。撤回不自动删除已有本机存档、荣耀账号或荣耀依法保留的信息，也不影响撤回前基于合法同意完成的处理。您可按下述方式进一步清除或提出请求。
  • 访问及清除本地游戏数据：界面展示关卡状态；您可在游戏设置或 Android 应用存储设置清除全部本地数据。清除后进度重置且不能通过我们的服务器恢复，请在确认前阅读提示。
  • 管理荣耀账号及服务数据：本游戏不建立独立注册账号。您可按荣耀官方规则在游戏中心账户中心管理账号信息，通过“游戏服务控制—停止游戏服务”等平台入口停止或解除相应服务关联，或联系荣耀提出访问、更正、复制、删除等请求。删除或停用本游戏不等于自动注销荣耀账号。
  • 联系运营方：如需查阅、复制、更正、补充、删除客服信息或必要游戏服务信息，获取副本、撤回或限制相关处理，请通过本政策末尾邮箱联系我们。涉及荣耀 SDK 或账号处理时，我们会协助核实并转交必要请求，也可直接通过荣耀隐私问题页面联系荣耀。我们只核实处理请求所必需的信息，不索取账号密码或验证码。

六、未成年人保护与健康游戏

适龄提示：开发者建议 8 周岁及以上。该建议不等同于主管部门分级，也不替代平台实名与防沉迷规则。未成年人应在监护人同意和指导下阅读本政策、协议及荣耀相关规则；未满十四周岁的儿童尤其应由监护人共同阅读后使用。

荣耀登录流程依平台开通和适用规则提供实名校验、未成年人身份及游戏时间管控。需要实名或在不允许游戏的时间段时，游戏遵从 SDK 返回的限制结果，不用本地游客方式绕过。SDK 提示应结束游戏时，本游戏执行退出。实名资料提交至荣耀官方流程，游戏运营方不收取这些资料。若您认为我们通过客服误收集了儿童的信息，请联系下方邮箱，我们会核实并依法处理。

健康游戏忠告：抵制不良游戏，拒绝盗版游戏。注意自我保护，谨防受骗上当。适度游戏益脑，沉迷游戏伤身。合理安排时间，享受健康生活。
